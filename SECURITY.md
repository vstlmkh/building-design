# Security

This package contains agent instructions, Python utilities, and an installer that writes into Claude Code and Kimi Code skill directories. Review the source before installation. The installer preserves existing files unless `--force` is explicit.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/vstlmkh/building-design/security/advisories/new). Do not include credentials, private project assets, or exploit details in a public issue.
